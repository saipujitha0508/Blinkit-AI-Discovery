# Phase 1 — Project Setup Guide (for beginners)

## What we finished

We created the empty project "house": folders and starter files only.

No reviews collected yet. No AI connected yet. No dashboard running yet.

## What each important file means

| File | Meaning |
|------|---------|
| `README.md` | Project overview in plain English |
| `requirements.txt` | Shopping list of Python packages |
| `.env.example` | Example of where secret API keys will go |
| `.gitignore` | Tells Git which files not to upload (secrets, junk) |
| `src/__init__.py` | Marks `src` as a Python package (a code folder) |

## How to check Phase 1 yourself in Cursor

1. Look at the left sidebar (Explorer).
2. Confirm you see: `app`, `src`, `data`, `docs`, `notebooks`, `scripts`, `tests`.
3. Open `README.md` and skim the folder diagram.
4. Open `.env.example` — you should see placeholder key names, not real secrets.

## What we will NOT do until you say "go"

- Install Python packages
- Connect Apify / Gemini / Supabase
- Collect any live reviews
- Build the dashboard

Reply that Phase 1 looks good when you are ready for Phase 2.
